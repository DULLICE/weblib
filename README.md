# 仙侠光影

两个纯原生 Canvas 实现的仙侠风格光影页面,无任何依赖,浏览器直接打开即可。

## 流光镜影 · `index.html`

夜色冷青。明月带月海地形,流光缓慢幻化,山峦叠翠,轻烟缭绕,燕雀群飞,镜湖倒影。

- 鼠标移入时,流光向指针弯曲汇聚,指针化作变色灵光并撒下光尘拖尾
- 鼠标靠近燕雀时,雀群受惊四散,远离后缓缓归群

## 暮霞瑶台 · `muxia-yaotai.html`

暮色暖金。金乌西沉,神光如扇,云海翻涌,桃花瓣落,流萤明灭,仙鹤缓飞。

- 鼠标移入时,落日神光缓缓朝指针汇聚加亮,指针化作金红灵火,花瓣绕指针回旋
- 鼠标靠近时,流萤与仙鹤受惊四散,远离后缓缓归群
