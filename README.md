# 仙侠光影集

纯原生 Canvas 实现的仙侠意境光影页面,无任何依赖,浏览器直接打开即可。三个页面通过角落的竖排链接互相跳转。

## 流光镜影(`index.html`)· 夜境

青碧夜色:流光缓慢幻化、山峦叠翠、轻烟缭绕、燕雀群飞、镜湖倒影、月面地形。

- 鼠标移入时,流光向指针弯曲汇聚,指针化作变色灵光并撒下光尘拖尾
- 鼠标靠近燕雀时,雀群受惊四散,远离后缓缓归群

## 云海仙阙(`yunhai-xianque.html`)· 晨曦

破晓金霞:朝阳霞光光柱旋转、浮空仙岛垂落光瀑、楼阁灯火、云海翻涌、仙鹤翩跹、落英成雨。

- 指针化作暖金灵光,云海在指针下方缓缓荡开豁口
- 花瓣在指尖绕旋起舞,仙鹤优雅侧身避让

## 暮霞瑶台(`muxia-yaotai.html`)· 黄昏

金乌西沉:落日神光、霞色层云、桃花花雨、流萤明灭、群山如黛、仙鹤远影。

- 桃花花雨在指尖成涡旋舞,流萤与仙鹤受惊四散
